# Restudio OSes Repository

**Official repository for Restudio operating system packages, security updates, and release infrastructure.**

Maintained by **Restudio Software Laboratories**.

## Overview

Restudio OSes Repository is a project dedicated to supporting the maintenance, security, and distribution of software packages for operating systems developed and maintained by Restudio Software Laboratories.

The repository aims to establish a reliable foundation for delivering system-specific packages, security fixes, and future updates.

## Supported Operating Systems

### MidwOS Horizon 1.0

MidwOS Horizon 1.0 is a desktop operating system designed for programming, development, and productivity.

Restudio OSes Repository is intended to support its maintenance and provide a foundation for future package distribution and security updates.

Additional Restudio operating systems may be supported in the future.

## Repository Goals

- Provide packages developed and maintained by Restudio Software Laboratories.
- Establish a controlled process for security updates.
- Verify packages before release.
- Support signed packages and trusted repository metadata.
- Keep feature updates and ordinary system changes under user control.
- Maintain documentation for package management and release procedures.

## Update Policy

Restudio aims to distinguish security updates from feature updates and ordinary software changes.

Security fixes will be reviewed, tested, and made available through the designated distribution channels when appropriate.

Feature updates and other non-security changes will remain subject to the user's update preferences.

The availability of an update does not imply automatic installation. Installation behavior will depend on the operating system's configured update policy.

## Package Integrity and Security

Package integrity and authenticity are essential to this project.

The repository plans to use appropriate package-signing and repository-metadata verification mechanisms before distributing packages to users.

Security-sensitive signing keys must be protected and must not be committed to this source repository.

## Repository Structure

The repository may contain:

- Package build definitions and source files.
- Security and release policies.
- Build and verification scripts.
- Documentation for supported operating systems.
- Configuration required to prepare package repositories.

The actual package-distribution infrastructure may be hosted separately from this source repository.

## Project Status

This project is under development. Repository infrastructure, package publication, security-update workflows, and supported update channels will be introduced as they are implemented and tested.

No package or update should be considered officially available until it has been published through a verified release channel.
